# Akasha

留一点时间，给阅读。

一个本地论文工作台。导入 PDF，整理分析，回到原文核对证据。
笔记、收藏和阅读进度，留在自己这里。

## 开始

需要 Python 3.12+、Docker Compose。已附浅青绿前端的构建文件；修改页面时再安装 Node 20.19。

按 [启动说明](README_ZH.md) 配置模型服务，启动 API、worker 和 beat，然后打开：

```text
http://127.0.0.1:8420/app/
```

网页登录用应用 `API_TOKEN`。不是模型的 API Key。

## 边界

- 分析只是线索。重要结论，请回到原文。
- 扫描版论文需要 OCR；mock 只用于测试。
- 不附带密钥、论文、数据库或原部署配置。
- 保留 `paperintel`、`paperctl` 等内部名称，兼容现有代码。

交付代码已独立构建：前端 290 项、后端离线 534 项测试通过。这不代表所有真实模型都已验证。
单独安装 wheel 时，`selftest` 仍依赖源码中的测试夹具；请保留完整项目。
